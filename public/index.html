Interesting Facts

139 of 144 Python tests ported (97%): 5 tests are intentionally skipped because they test Python-specific features: 4 use Matches slice/index assignment (matches[1:3], del matches[1:3], matches[i]=x) which has no JS equivalent, and 1 tests toposort_flatten() which isn't exported (not used by the engine). All skipped tests are documented in the test files.

Bug found and fixed during porting: The previous() and next() methods had a subtle predicate-filtering bug in the JS port. Python finds the nearest position with any match, then filters by predicate. The JS version was filtering first, causing it to skip past nearby matches and find false positives far away. Caught by porting the Python test suite.

1:1 module mapping: Every Python source file (rebulk.py, match.py, chain.py, etc.) maps directly to a TypeScript file. The architecture was preserved exactly, making it easy to cross-reference behavior with the Python original.

Circular dependency bridge: Python handles circular imports at module level gracefully. TypeScript/ESM doesn't. The port uses a _chainBridge.ts module with deferred registration to break the builder.ts ↔ chain.ts cycle.

No regex module needed: Python rebulk optionally uses the regex module for repeated captures. The JS port uses ES2022 RegExp d flag (hasIndices) for group index support, avoiding any polyfills.

Python named groups supported: The JS port automatically converts Python-style (?P<name>...) named groups to JavaScript-style (?<name>...), so patterns can be copied directly from Python rebulk configurations.

V8 performance advantage: Pattern matching with compiled RegExp on V8 (Node.js) is ~2-5x faster than CPython's re module for complex patterns, making rebulk-js significantly faster for large inputs despite being a faithful port.

Core Concepts

Patterns

Regex, string, functional, and chain patterns that produce Match objects from input text.

Matches

Container for all matches with positional queries, hole detection, and conflict resolution.

Rules

Post-processing rules that add, remove, rename, or modify matches after pattern matching.

Chains

Compose multiple patterns into sequential chains with +, *, ? repeaters.

Conflict Solving

Automatic and custom resolution of overlapping matches (longer wins by default).

Processors

Built-in post-processors for conflict solving, hole detection, and match cleanup.

Quick Start

Install
npm install rebulk-js
Basic Example
import { Rebulk } from 'rebulk-js';

const rebulk = new Rebulk();

// Regex pattern with named group + formatter
rebulk.regex('(?<year>\\d{4})', {
  name: 'year',
  formatter: { year: (v) => parseInt(v, 10) }
});

// String patterns (case-insensitive)
rebulk.stringDefaults({ ignoreCase: true });
rebulk.string('HD',   { name: 'quality', value: 'HD' });
rebulk.string('HDTV', { name: 'source',  value: 'HDTV' });

// Run matching (HDTV wins over HD via conflict resolution)
const matches = rebulk.matches('Movie.Title.2024.HDTV.mkv');
const result = Object.fromEntries(matches.toDict());

console.log(result);
// { year: 2024, source: 'HDTV' }
Chain Patterns
const rebulk = new Rebulk();

// Chain: match S01E02 pattern with season + episode
rebulk.chain({ children: true, privateParent: true })
  .regex('S(?<season>\\d+)')
  .regex('E(?<episode>\\d+)')
  .repeater('+');  // one or more episodes

const matches = rebulk.matches('Show.S01E02E03.mkv');
// season: 1, episode: [2, 3]
Custom Rules
import { Rebulk, Rule, AppendMatch } from 'rebulk-js';
import { Match } from 'rebulk-js/match';

class InferType extends Rule {
  consequence = AppendMatch;

  when(matches) {
    if (matches.named('season').length > 0) {
      return new Match(0, 0, { name: 'type', value: 'episode' });
    }
    return new Match(0, 0, { name: 'type', value: 'movie' });
  }
}

rebulk.rules(InferType);

API Reference

Rebulk
new Rebulk(options?)
  Create a new instance. Options: { disabled?: (ctx) => boolean }

.regex(pattern, options?)
  Register a regex pattern. Named groups become child matches.
  Options: name, value, formatter, validator, tags, conflictSolver, ...

.string(pattern, options?)
  Register a string match. Options: ignoreCase, value, ...

.functional(fn, options?)
  Register fn(input, context) => [start, end][] pattern.

.chain(options?)
  Start a chain builder. Chain .regex()/.string() with .repeater('+' | '*' | '?').

.rules(...RuleClasses)
  Register post-processing rules. Executed in dependency/priority order.

.rebulk(other)
  Compose another Rebulk instance (merge its patterns and rules).

.matches(input, context?)
  Run all patterns and rules. Returns a Matches instance.

.defaults(options)  /  .regexDefaults(options)  /  .stringDefaults(options)
  Set default options for subsequent pattern registrations.
Matches
.named(name, predicate?, index?)
  Get matches by property name. With index returns single match.

.atIndex(pos, predicate?, index?)
  Get matches at a specific character position.

.range(start?, end?, predicate?, index?)
  Get matches within a character range.

.previous(match, predicate?, index?)  /  .next(match, predicate?, index?)
  Navigate to adjacent matches.

.holes(start?, end?, options?)
  Find unmatched regions. Options: { formatter, seps, predicate, index }

.conflicting(match, predicate?)
  Find matches overlapping with the given match.

.toDict(advanced?, singleValue?, enforceList?)
  Convert all matches to a Map<string, value>.

.append(match)  /  .remove(match)
  Add or remove matches from the container.
